Supabase 接続設定

初回のみ設定が必要です。入力内容はブラウザに保存されます。

① supabase.com でプロジェクト作成
② SQL Editor で下記を実行してテーブルを作成
CREATE TABLE paint_records ( id bigserial PRIMARY KEY, registered_date date, customer_name text NOT NULL, car_name text, reg_number text, paint_area text, paint_type text, color_no1 text, color_no2 text, mix_detail text, updated_at timestamptz DEFAULT now() ); -- RLS を無効化（社内利用向け簡易設定） ALTER TABLE paint_records DISABLE ROW LEVEL SECURITY;
③ Settings → API から URL と anon key をコピー
