Supabase 接続設定

初回のみ設定が必要です。入力内容はブラウザに保存されます。

① supabase.com でプロジェクト作成
② SQL Editor で下記を実行してテーブルを作成
-- 塗装記録テーブル CREATE TABLE paint_records ( id bigserial PRIMARY KEY, registered_date date, customer_name text NOT NULL, car_name text, reg_number text, paint_area text, paint_type text, color_no1 text, color_no2 text, mix_detail text, updated_at timestamptz DEFAULT now() ); ALTER TABLE paint_records DISABLE ROW LEVEL SECURITY; -- ユーザーマスタ CREATE TABLE user_master ( id bigserial PRIMARY KEY, employee_code text NOT NULL UNIQUE, employee_name text NOT NULL, role text NOT NULL DEFAULT 'user', password text NOT NULL, created_at timestamptz DEFAULT now() ); ALTER TABLE user_master DISABLE ROW LEVEL SECURITY; -- 初期管理者 INSERT INTO user_master (employee_code, employee_name, role, password) VALUES ('001', '管理者', 'admin', 'admin');
③ Settings → API Keys → Legacy タブ から anon key をコピー
④ Settings → Data API から Project URL をコピー
